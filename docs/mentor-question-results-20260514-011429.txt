67. USER
what is a nested loop?

67. AI MENTOR
A nested loop is a loop inside another loop. The inner loop runs completely for each iteration of the outer loop. For example, to print a 3x3 grid of stars:

for (int i = 0; i < 3; i++) {
for (int j = 0; j < 3; j++) {
printf("*");
}
printf("\n");
}
